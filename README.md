# RARITONE-DAY-6-AIML-AKSHITH
**Task 1 – Body Measurement using Pose Detection**
Implemented real-time pose detection and body measurement estimation using MediaPipe and OpenCV. Extracted body landmarks and estimated measurements such as shoulder width, hip width, and height from webcam input.

**Task 2 – Testing Pose Detection on Images and Videos**
Tested pose detection on multiple images and videos including front pose, side pose, sitting posture, exercise movements, and low-light conditions. Observed landmark accuracy, tracking stability, and performance under different scenarios.

**Task 3 – Research on Clothing Segmentation AI**
Researched clothing segmentation techniques used in virtual try-on systems. Studied semantic segmentation, human parsing, segmentation models, applications, and challenges involved in separating clothing regions from the human body.

**Task 4 – Creating a Basic Recommendation Dataset**
Created a simple clothing recommendation dataset containing user information, clothing type, color, size, and style. Understood how datasets help AI recommendation systems generate personalized outfit suggestions.

**Task 5 – Backend API Integration**
Integrated AI-generated body measurement outputs with backend APIs using Flask. Sent measurement data in JSON format from the pose detection system to the backend server using HTTP requests and verified successful real-time communication.
